# Financial Engineering Lab. 웹사이트

한국외대 Finance & AI융합학부 공형우 교수 연구실의 정적 HTML 사이트입니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` 등 7개 HTML, `style.css`, `images/` | 실제 사이트. 호스팅에 올리는 파일은 이것뿐입니다. |
| `data/site.json` | 모든 내용의 원본. HTML은 이 파일에서 생성됩니다. |
| `build.js` | `site.json`을 읽어 HTML 7개를 다시 만듭니다. |
| `admin/` | 로컬 관리 페이지 (서버, 화면, 비밀번호 설정). 호스팅에 올리지 마세요. |
| `admin.bat` | 관리 페이지 실행 (Windows). |

## 내용 수정하기

1. `admin.bat`을 더블클릭합니다. Node.js가 필요합니다 (https://nodejs.org).
2. 브라우저에 관리 페이지가 열립니다. 주소는 http://127.0.0.1:8080/admin 입니다.
3. 처음 비밀번호는 `felab` 입니다. 로그인 후 Password 탭에서 바꾸세요.
4. 탭별로 내용을 고치고 **Save & rebuild**를 누르면 HTML이 다시 생성됩니다. 상단 **Preview site**로 결과를 확인합니다.
5. 생성된 HTML 파일과 `images/` 폴더를 호스팅에 올리면 반영됩니다.

관리 서버는 이 PC 안에서만 (127.0.0.1) 열리므로 다른 사람은 접속할 수 없습니다. 관리 페이지 없이 `data/site.json`을 직접 고친 뒤 `node build.js`를 실행해도 됩니다.

## 입력 규칙

- **논문 저자**: 쉼표로 구분해 전체 이름을 적습니다. 교신저자는 이름 뒤에 `†`를 붙입니다. 교수 이름은 자동으로 굵게, Members 탭에 등록된 이름은 자동으로 밑줄이 표시됩니다.
- **논문 링크**: 한 줄에 하나씩 `라벨 주소` 형식입니다. 예: `paper https://doi.org/...`
- **SNS 링크**: 한 줄에 하나씩 `종류 주소` 형식입니다. 종류는 `linkedin`, `github`, `scholar`, `website` 중 하나입니다.
- **News 날짜**: `YYYY-MM` 형식입니다. 같은 달 항목은 한 제목 아래 묶입니다. 위에 있을수록 최신입니다.
- **사진**: Photo 칸의 파일 선택으로 올리면 `images/`에 저장되고 경로가 자동으로 채워집니다.
- 대부분의 텍스트 칸은 HTML 태그를 그대로 쓸 수 있습니다 (`<i>`, `<a>`, `&amp;` 등).

## Blog

메뉴 맨 오른쪽의 Blog는 학회 참석, 세미나, 모임 같은 소식을 사진과 함께 올리는 페이지입니다. 글은 카드 형태로 쌓이고, 카드를 누르면 `blog/글아이디.html`로 만들어진 글 페이지가 열립니다. 첫 번째 사진이 카드 썸네일이 됩니다.

- 관리 페이지 Blog 탭에서 글을 추가합니다. 날짜, 카테고리, 제목 (영문과 한글), 장소, 본문, 사진을 넣습니다.
- 사진은 파일 선택에서 여러 장을 한 번에 고르면 `images/blog/`에 올라가고 경로가 자동으로 채워집니다. 각 줄의 `|` 뒤에 캡션을 적습니다.
- 카테고리는 같은 탭 아래 칸에서 `키 이모지 이름` 형식으로 관리합니다.
- General 탭에서 Blog 메뉴를 숨기거나, 외부 블로그 주소로 연결하도록 바꿀 수 있습니다.

## 강의 목록 자동 갱신

Courses 페이지는 학교 강의시간표 시스템 (wis.hufs.ac.kr) 에서 공형우 교수 담당 강의를 조회해 채웁니다.

- 관리 페이지 Courses 탭의 **Fetch from HUFS timetable** 버튼을 누르거나, 터미널에서 `node fetch-courses.js`를 실행합니다.
- 2025년부터 올해 다음 해까지 1학기와 2학기를 조회하고, 최신 학기가 위로 오도록 정렬합니다.
- 교수 이름, 학과 코드 (Finance & AI융합전공은 `A9B01`), 캠퍼스는 `fetch-courses.js` 상단에서 바꿀 수 있습니다.
- 학교 시스템이 바뀌어 조회가 실패하면 기존 목록은 그대로 남습니다.

## 백업

저장할 때마다 직전 내용이 `data/site.json.bak`에 남습니다. 잘못 저장했다면 이 파일을 `site.json`으로 되돌린 뒤 `node build.js`를 실행하세요.
